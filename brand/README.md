# SourceSteward brand

SourceSteward uses the BundleDock/WorkHarbor family palette: navy #0b2545, deep blue #13315c,
turquoise #5eead4 and a decorative #2a4a7a outline. Its original mark is a change graph beside
an open curved guide rail on a rounded navy tile. Color is accompanied by geometry and accessible names.

Headings use Bricolage Grotesque; body text uses IBM Plex Sans. Font files are copied from
BundleDock's reviewed brand/font sources and hosted locally. Preserve the adjacent SIL Open
Font License files in docs/assets/fonts/. The site uses fallback fonts when local fonts cannot
load. The SVG logo uses geometry only and has no font or external resource dependency.

Original mark, CSS and page layout: EUPL-1.2. The family styling does not imply a shared
repository policy. No raster AI generation or third-party logo copying was used.
