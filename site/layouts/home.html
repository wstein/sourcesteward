Rust CLIcommand: stwexperimental

Plan Git changes, inspect branch history, and hand off work across repositories.

SourceSteward is a Rust CLI for standalone Git repositories and workspaces with submodules. Preview where staged fixes belong, see which files would conflict in a rebase, and inspect the history of ref changes.

Get started

Install the stw command, then run a read-only check in any Git checkout.

  1. 1

    Install

    $ brew install wstein/tap/stw
    $ curl -fsSL https://wstein.github.io/sourcesteward/install.sh | sh

    The script checks the archive SHA-256 and installs into ~/.local/bin. Set STW_INSTALL_DIR for another directory, or append -s -- v0.6.0 to pin a release.

  2. 2

    Run a read-only check

    $ stw status --offline

  3. SourceSteward is experimental. Review the plan before any operation that changes Git history.
