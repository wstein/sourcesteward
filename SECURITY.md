# Security policy

Use GitHub's [private vulnerability reporting](https://github.com/wstein/sourcesteward/security/advisories/new)
to report a suspected vulnerability in SourceSteward. Please keep details out
of public issues and pull requests while the report is investigated.

Include the affected SourceSteward version or commit, operating system and
architecture, Git version, affected command, and potential impact. If you
can reproduce the issue in a disposable repository, include minimal steps
and relevant output. Remove tokens, credentials, and private repository
contents from attachments and logs.

For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/wstein/sourcesteward/issues).
