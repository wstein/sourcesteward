IMPLEMENTED TODAY

More than help and version.

Every data command offers human output and --json. Git and jj retain their native identities and limits. Check your installed version and command help.

Inspect and query

help · version · inspect · inventory

stw inventory . --query dirty \
  --scope disk --scope untracked --json

Local observations; no fetch or snapshot. Known false queries exit 0; unknown evidence exits 1.

Create an isolated workspace

workspace plan · workspace apply

stw workspace plan /path/to/source --base HEAD \
  --destination /path/to/task --task issue-42 \
  --owner developer --state-dir /path/to/state --json

Use an unused destination and existing private mode0700 state directory. jj may use @ as its base. Planning stores state; reviewed apply needs --authorize.

Hand off and prepare retirement

workspace handoff · workspace retire-plan

stw workspace handoff /path/to/task \
  --state-dir /path/to/state --json

Describe owned work and retention evidence. Preparation does not delete registrations or files.

Review and apply local tidy

tidy plan · tidy apply

stw tidy plan . --base main \
  --ref finished-task --json

Select an explicit native base/reference. Uncertain work retains. Apply needs a stored plan; owned retirement has separate registration and exact-path file selections.

Read GitHub evidence

hosting repo · hosting pr · hosting ci

stw hosting ci 42 . \
  --repo owner/project --json

repo is offline. PR/CI uses gh 2.102.0+ authentication and bounded HTTPS reads. No push, PR edit, merge or CI rerun.

Use the optional gh extension

gh jj repo · gh jj pr · gh jj ci

gh jj pr 42 /path/to/jj-workspace \
  --repo owner/project --json

Shares SourceSteward operations; requires jj ownership and explicit extension installation. No replacement of an existing extension.
