# Tasks: Hook and bypass disclosure

**Input**: [spec.md](spec.md), [plan.md](plan.md), [research.md](research.md), [data-model.md](data-model.md), [contracts/hooks.md](contracts/hooks.md), [analysis.md](analysis.md).
**Tests**: Required by constitution principle IV. Write each behavior test and observe it fail before the implementation. Task checkboxes record execution, not design approval.
**Work items**: Tasks are grouped into six work items, WI1 to WI6. Each is one reviewable change that builds on the previous one and ends with `make check` green; WI order is the stacking order of the pull requests. Each task names the requirements (FR), stories (US) and success criteria (SC) it covers.
**Authorization**: Building `bin/stw`, running the smoke scripts locally and any release or documentation build need the maintainer's explicit approval under the workspace policy; CI lanes run on push. Source tests, formatting, vet and test compilation run freely.
