Decisions and findings of this package (no requirement or contract was changed):

- A tip with no proof and no reason is still `integration-not-proven` (Spec 029), because the evidence record requires at least one reason for `needs-review`.
- Grafts, shallow metadata and alternates are hard stops only in a local-reference planning context; apply keeps the strict admission, so a repository with these files plans every proof-eligible ref as retained and apply refuses.
