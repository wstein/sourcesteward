## Surprises and findings for the owner

- **Product defect, not an environment problem (review of PR #251).** The per-repository analysis has a fixed 60 s deadline. Once it runs out,
  every remaining worktree of that repository is reported as `git-ownership-refused` instead of `deadline-exceeded` (the spec requires
  `deadline-exceeded`), and the 140 true `deadline-exceeded` items (139 branches, 1 worktree) come from the same window. The window does not
  scale to 418 (workharbor) and 186 (sourcesteward) worktrees, and `--timeout` can only shorten it, not lengthen it. My data is consistent
  with this: the 380 `git-ownership-refused` are 289 workharbor and 91 sourcesteward worktrees, the two largest repositories, and they sit
  next to the deadline items there. My earlier guesses that the devcontainer or a concurrent test run caused them are withdrawn. The
  reviewer traced the mechanism in the code: `git.go:45-47`, `inspection.go:27-30,59-60` and `observe_worktrees.go:145` against the
  requirement at `spec.md:327` (a read that fails while the context is done is `Incomplete` `deadline-exceeded`). It is tracked as issues
  #252 and #253. The defect is open; this evidence does not fix it.
- Of the 670 worktree candidates (667 worktree, 3 stale-worktree; the same number as the registrations), 397 are `evidence-incomplete`
  (380 `git-ownership-refused`, 15 `git-tree-refused`, 1 `observation-failed`, 1 `deadline-exceeded`).
- The two runs disagree by 12 safe items because the workspace is live; the overview is a sample, as its own notice says
  ("Evidence is sampled and nontransactional").
- The text overview is grouped by repository, with the owner shown per row; it is not grouped by owner as SC-010 words it. The JSON carries
  `owner`, `owner_source` and `scope` for every candidate.
- Every repository reports the notice `tracking-requires-online`; tracking references were therefore not judged (no network by design).
- The dry run is not a literal copy of the 2026-10-23 situation: it is a plan-only run over the current, larger live
  workspace. A copy was not built.
